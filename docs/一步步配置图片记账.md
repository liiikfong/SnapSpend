# 一步步配置「通过图片记账」

按顺序做完下面每一步即可在网页上用「从图片识别」记账，之后还可以接 Shortcut。

---

## 第 1 步：在 Supabase 建「识别结果临时表」

1. 打开浏览器，进入 [https://supabase.com/dashboard](https://supabase.com/dashboard)，登录后点进你的 **SnapSpend** 项目。
2. 左侧点 **SQL Editor**。
3. 新建一个查询（或清空当前内容）。
4. 打开本地的 **`docs/run-pending-recognitions.sql`**，把里面**整段 SQL** 复制到 Supabase 的 SQL 编辑器里（不要只写文件路径）。
5. 点右下角 **Run**。
6. 看到成功提示即可。若提示表已存在也可以忽略。

---

## 第 2 步：把代码推到 GitHub（若还没推过）

1. 在项目根目录打开终端，执行：
   ```bash
   git init
   git add .
   git commit -m "SnapSpend: web + image recognize"
   ```
2. 在 [GitHub](https://github.com/new) 新建一个仓库（例如名字 `SnapSpend`），不要勾选「Add a README」。
3. 按 GitHub 页面上提示，在本地执行（把 `你的用户名` 和 `SnapSpend` 换成你的）：
   ```bash
   git remote add origin https://github.com/你的用户名/SnapSpend.git
   git branch -M main
   git push -u origin main
   ```

若你已经推过，可跳过本步。

---

## 第 3 步：在 Vercel 导入项目并部署

1. 打开 [https://vercel.com](https://vercel.com)，用 GitHub 登录。
2. 点 **Add New… → Project**。
3. 在列表里找到 **SnapSpend**（或你起的仓库名），点 **Import**。
4. **不要**改 Framework Preset 和 Build 设置（用项目里自带的即可），直接点 **Deploy**。
5. 等部署完成，记下给你的域名，例如：`snapspend-xxx.vercel.app`。

---

## 第 4 步：在 Vercel 里配环境变量

1. 在 Vercel 里点进刚导入的 **SnapSpend** 项目。
2. 顶部点 **Settings**，左侧点 **Environment Variables**。
3. 按下面表格，**一条一条**添加（每填完一行 Name + Value 就点一次 Save，再继续下一条）：

| Name（变量名） | Value（值） | 从哪里复制 |
|----------------|-------------|------------|
| `VITE_SUPABASE_URL` | `https://xxxxx.supabase.co` | Supabase → Project Settings → **General** → Project URL |
| `VITE_SUPABASE_ANON_KEY` | `eyJ...` 一长串 | Supabase → Project Settings → **API** → anon public（或 Publishable key） |
| `SUPABASE_URL` | 和上面 **完全一样** 的 Project URL | 同上 |
| `SUPABASE_SERVICE_ROLE_KEY` | `eyJ...` 另一长串 | Supabase → Project Settings → **API** → **service_role**（Secret key，不要用 anon） |
| `OPENAI_API_KEY` | `sk-...` | [OpenAI API Keys](https://platform.openai.com/api-keys) 里创建并复制 |

4. 每条添加时，**Environment** 三个都勾选（Production / Preview / Development），再点 Save。
5. 确认 5 个变量都出现在列表里。

---

## 第 5 步：重新部署一次

环境变量改完后，要再部署一次才会生效。

1. 在 Vercel 项目里点 **Deployments**。
2. 找到最近一次部署，右侧点 **⋯** → **Redeploy**。
3. 再点一次 **Redeploy** 确认。
4. 等状态变成 **Ready**。

---

## 第 6 步：在网页上试「从图片识别」

1. 在浏览器打开：**https://你的域名/record**（把「你的域名」换成第 3 步记下的，如 `snapspend-xxx.vercel.app`）。
2. 若未登录，先登录或注册。
3. 在记账区域下方找到 **「从图片识别」** 按钮，点一下。
4. 选一张**账单 / 转账 / 付款成功**的截图（银行推送、微信转账、支付宝付款页等都可以）。
5. 等几秒，应出现「正在识别图片…」，然后表单里会自动填上金额、商户、日期等。
6. 有需要就改一下分类或备注，点 **「记一笔」**，这条记录会存到 Supabase，多设备同步。

若报错「识别失败」或 500，请回到第 4 步检查 5 个环境变量是否都填对（尤其是 `OPENAI_API_KEY` 和 `SUPABASE_SERVICE_ROLE_KEY`）。

---

## 第 7 步（可选）：本地开发时也能测「从图片识别」

本地用 `npm run dev` 时，前端没有 `/api`，需要把请求指到已部署的 API：

1. 打开项目根目录的 **`.env`** 文件。
2. 加一行（把域名换成你第 3 步的 Vercel 域名）：
   ```env
   VITE_API_BASE=https://你的域名.vercel.app
   ```
3. 保存后重启一次 `npm run dev`，再在本地页面点「从图片识别」，就会请求你部署好的 API。

---

## 小结

| 步骤 | 做了什么 |
|------|----------|
| 1 | Supabase 执行 `run-pending-recognitions.sql` |
| 2 | 代码推到 GitHub |
| 3 | Vercel 导入项目并部署，记下域名 |
| 4 | Vercel 里添加 5 个环境变量 |
| 5 | Redeploy 一次 |
| 6 | 打开 你的域名/record，点「从图片识别」试一张图 |
| 7 | （可选）本地 .env 加 VITE_API_BASE |

做完 1～6 后，就可以在网页上通过图片记账了。接下去若要接 iPhone Shortcut，可以看 **`docs/图片记账与Shortcut.md`**。
