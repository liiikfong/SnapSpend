# 环境变量配置步骤

项目里已经有一份 `.env` 文件（从 `.env.example` 复制来的），你只需要把占位符换成 Supabase 的真实值。

---

## 第 1 步：打开 Supabase 项目设置

1. 浏览器打开 [https://supabase.com/dashboard](https://supabase.com/dashboard)
2. 登录后，点击你的 **SnapSpend** 项目
3. 左侧边栏最下方点 **Project Settings**（齿轮图标）
4. 在设置里点 **API**

---

## 第 2 步：复制两个值

在 **API** 页面可以看到：

| 需要复制的项 | 在页面上的名字 | 说明 |
|-------------|----------------|------|
| 项目 URL | **Project URL** | 类似 `https://abcdefgh.supabase.co` |
| 匿名密钥 | **Project API keys** 里 **anon**、**public** 那一行的 key | 一长串以 `eyJ...` 开头的字符串 |

**注意：** 只复制 **anon public** 的 key，不要用 `service_role`（那个权限太高，不能放在前端）。

---

## 第 3 步：填进本地的 .env

1. 在 Cursor 里打开项目根目录下的 **`.env`** 文件（和 `package.json` 同一层）
2. 把这两行里的占位符替换成你刚复制的值：

```env
VITE_SUPABASE_URL=这里粘贴 Project URL
VITE_SUPABASE_ANON_KEY=这里粘贴 anon public key
```

3. 保存文件（不要加引号、不要有多余空格）

示例（请用你自己的值）：

```env
VITE_SUPABASE_URL=https://abcdefghijk.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIsInJlZiI6ImFiY2RlZmdoaWprIiwicm9sZSI6ImFub24iLCJpYXQiOjE2...
```

---

## 第 4 步：验证

在项目根目录执行：

```bash
npm run dev
```

浏览器打开 http://localhost:5173，能打开登录/注册页且没有报错，说明环境变量已生效。
